System requirements

  • PHP 8.2 or newer
  • MySQL 8.0+ or MariaDB 10.6+
  • PDO and PDO MySQL
  • JSON, Mbstring, Ctype, Session, OpenSSL, Fileinfo, and cURL extensions
  • Writable Barama application runtime directories
  • Apache with mod_rewrite/AllowOverride or supported Nginx front-controller routing
  • HTTPS is recommended for production use

No Node.js production runtime, Composer install command, manual migration command, or customer-created .env file is required.

One-click installation

  1. Upload and extract the customer ZIP into the intended website root.
  2. Open the main domain in a browser. Barama redirects automatically to /installer/.
  3. Complete License & Terms.
  4. Confirm Requirements.
  5. Connect the Database.
  6. Complete Website settings, including the first administrator and email delivery.
  7. Review System Health / Finish and open the website.

The customer-facing installer always contains exactly five visible steps. Permissions checks remain inside Requirements.

License verification

The installer supports a Ton Samith direct license key or a CodeCanyon / Envato purchase code through the same license field.

Validation is handled through the Ton Samith License Manager. The original purchase code/license key is not stored in persistent runtime state after successful activation.

Accounts and workspaces

  • User Account: /account
  • Company / Vendor Workspace: /developer
  • Public Company Directory: /company
  • Administrator Dashboard: /dashboard

Access is permission controlled. Public registration does not grant company/vendor or administrator permissions automatically.

Email delivery

Step 4 of the installer supports SMTP (recommended) or PHP mail. The installer requires a successful test email before installation can finish.

SMTP passwords are stored only in protected runtime configuration after successful installation and are not repopulated into installer forms after validation errors.

Scheduled notification jobs

For saved-search alerts and queued email delivery, schedule the following command with your hosting control panel or cron facility:

php /absolute/path/to/barama/tools/notifications.php run

Useful variants:

  • php tools/notifications.php alerts all --limit=100
  • php tools/notifications.php alerts daily --limit=100
  • php tools/notifications.php alerts weekly --limit=100
  • php tools/notifications.php outbox 100

Run the command from the installed Barama package and use the PHP CLI version supported by the web application.

Upgrade

  1. Create a current backup of both files and database.
  2. Upload and extract the newer supported package over the existing installation.
  3. Open the main domain. Barama redirects to /updater/ when the installed version differs from the package version.
  4. Authenticate with an active administrator account and confirm the backup.
  5. The updater validates the installed license and applies only pending ordered migrations.
  6. Return to the website and verify important customer/admin workflows before removing the backup.

Downgrades are not supported.
